# NumStrata

> Codename: NumStrata
> Genre: Puzzle / Math / Strategy / Mahjong-Solitaire
> Platform: Mobile (Android/iOS)
> Engine: Unity (C#)

NumStrata là game giải đố kết hợp tính toán số học và cơ chế chồng lớp kiểu Mahjong. Người chơi cần vừa giải phép tính đúng vừa quản trị tài nguyên số để mở khóa các lớp tile và hoàn thành màn.

## Gameplay nhanh

1. Quan sát board 2.5D và các tile đang mở.
2. Chọn số và toán tử vào thanh công thức.
3. Hoàn thành phép tính đúng để xóa tile.
4. Quản lý số dư trên conveyor để duy trì nước đi.

## Điểm nổi bật

- Kết hợp puzzle số học với cảm giác chiến thuật của Mahjong layering.
- Luật deterministic, dễ học nhưng khó làm chủ.
- Có Campaign và Daily Challenge với tiến trình dài hạn.
